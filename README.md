# 🐍 SnakeAI

An enhanced implementation of the classic **Snake** game developed in **Python** with **Pygame**, featuring multiple game modes, intelligent AI opponents, customizable gameplay, and dynamic difficulty levels.

---

## 📖 Overview

SnakeAI is a modern version of the classic Snake game created as a personal portfolio project. The game combines traditional Snake mechanics with artificial intelligence, allowing players to compete against an AI or watch two AI agents compete against each other.

The project was developed following object-oriented programming principles and focuses on clean architecture, game logic, AI decision-making, and user experience.

---

## ✨ Features

- 🎮 Multiple game modes
  - Player vs AI
  - AI vs AI
- 🤖 Intelligent AI opponent
- 🎯 Three difficulty levels
  - Easy
  - Medium
  - Hard
- 🧱 Dynamic walls depending on the selected difficulty
- 🎨 Customizable snake colors
- 🏆 Winner announcement after each match
- 📊 Score tracking
- 🖥️ Interactive main menu
- 🔄 Restart game or return to the main menu after Game Over
- 🍎 Random food generation
- ⚡ Smooth gameplay using Pygame

## 🚀 Installation

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/SnakeAI.git
```

### 2. Navigate to the project folder

```bash
cd SnakeAI
```

### 3. Install the dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the game

```bash
python main.py
```

## 🎮 Game Modes

### Player vs AI

Control your snake while competing against an AI opponent that tries to collect food and avoid collisions.

### AI vs AI

Watch two autonomous AI agents compete against each other. Each AI makes independent decisions to survive and collect food.

## 🤖 Artificial Intelligence

The AI is designed to make intelligent movement decisions by:

- Moving toward food
- Avoiding walls
- Avoiding self-collisions
- Avoiding enemy snake collisions
- Choosing safe paths whenever possible

Each AI agent plays autonomously without user intervention.
